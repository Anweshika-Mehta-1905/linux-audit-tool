Get the tool
Download & run in 3 steps

Click download, copy the script into your Linux terminal, and run. No package manager. No internet needed during the scan.

✓ Free forever ✓ Single file ✓ No install ✓ Read-only
1
Download the script above
Click the green button. A file called linux_audit.sh will download to your computer.
2
Copy it to your Linux terminal
Open a terminal (Ctrl+Alt+T in Ubuntu). Make the script executable.
chmod +x linux_audit.sh
3
Run the audit
Run as root for full results. Scroll with arrow keys, press Q to quit.
sudo ./linux_audit.sh 2>&1 | less -R
4
Save a report
Export results as a text file to keep, share, or add to your portfolio.
./linux_audit.sh --no-color > report.txt
What it checks
6 audit modules

Covers every major Linux attack surface — from file permissions to running processes.

🖥️
01
System Profile
  • OS, kernel, hostname, architecture
  • Current user, UID, groups
  • $PATH safety — dot/relative entries
  • Dangerous groups: docker, lxd, disk
🔑
02
Sudo Access
  • Passwordless sudo detection
  • Broad NOPASSWD permissions
  • /etc/sudoers read/write access
  • /etc/sudoers.d/* enumeration
⚡
03
SUID / SGID
  • Full filesystem SUID scan
  • Full filesystem SGID scan
  • GTFOBins cross-reference (50+)
  • Privilege escalation detection
🔒
04
File Permissions
  • /etc/shadow readable check
  • /etc/passwd, /etc/group write check
  • Crontab and systemd write access
  • World-writable directories
⏱️
05
Cron Jobs
  • /etc/crontab and /etc/cron.d/*
  • User crontab enumeration
  • Writable cron target detection
  • Missing scripts with writable parent
📡
06
Processes
  • All root (UID 0) processes
  • Executables in /tmp or /dev/shm
  • Deleted-on-disk process detection
  • Writable root process binaries
